# Personal-Blog-juan
en este repo lo que va haber es el código entero de la creación de un blog personal, en solitario

## Ejecutar en local
1. `cd blog_entero_python/Backend`
2. (Opcional) activar tu entorno virtual.
3. `uvicorn main:app --reload`
4. Abrir <http://localhost:8000/>; FastAPI redirige a `/frontend/index.html`.
